# ADR 004 — Chatbot: Telegram (grammY) primeiro, Baileys só experimental

**Status:** proposta (Etapa 8+)

- **grammY**: API oficial do Telegram, gratuita, sem risco de banimento.
- **Baileys**: API não oficial do WhatsApp — viola os termos e pode banir o número.
  Apenas experimento com número dedicado. Produção em WhatsApp → Cloud API oficial.
- **Botpress/Telegraf**: descartados (sobreposição / manutenção).
